History

Drap's Labs started as a NAS home server I set up for file storage purposes. Eventually I installed TrueNAS and Jellyfin.

The hardware it ran on at the time was VERY crappy, so in April of 2025, I upgraded the server by getting new hardware. During this time, I also bought one of the first domains for Drap's Labs. However, I had to sell this old domain for personal reasons. Then, I bought the one you're currently on.

I get bored sometimes, and would find myself wanting to messing around with the server management side of things. So, I created these projects so I could achieve that, while also providing tools to the public.

Drap's Labs then got its own Discord server, where users could see the status of Jellyfin, but then it expanded into a server where people could chat about whatever they want.

A mainpage was created for Drap's Labs for the base domain, however the code was stolen from another person. So, development of this very page began.
